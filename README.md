# Traventic Backend - Quote Pricing & Remittance Management System (RMS)

## Overview
This system generates travel quotes by retrieving relevant hotels, sightseeing activities, and transfers, and provides a complete **Remittance Management System (RMS)** API suite for member onboarding, 4-stage remittance workflows, beneficiary management, and agent dashboards.

---

## 📊 Pricing Logic

### Base Pricing Model

#### 1. **Hotel Pricing** (Occupancy-Optimized)
- **Base Rate**: Price per room per night for **2 adults**
- **Logic**: Maximize room occupancy before adding new rooms.
- **Formula**:
  - `rooms_needed = ceil(adults / max_occupancy)`
  - `extra_beds = adults - (rooms_needed * 2)` (if positive)
  - If `extra_bed_rate` exists, use it. Else 30% of room rate.

**Example 1 - High Occupancy (Max 4):**
```
Hotel: $120/night, Max Occ: 4, Extra Bed: $30
Adults: 4
Rooms: 1 (4 <= 4)
Base: $120
Extra Beds: 4 - 2 = 2 beds ($30 × 2 = $60)
Total: $180/night
```

**Example 2 - Standard Occupancy (Max 2):**
```
Hotel: $100/night, Max Occ: 2
Adults: 4
Rooms: 2 (4 / 2 = 2)
Base: $100 × 2 = $200
Extra Beds: 0
Total: $200/night
```

#### 2. **Sightseeing Pricing** (Type-Based)
- **SIC Tours** (Seat in Coach/Shared): Price **per person** (multiplied by adults)
- **Private Tours**: Price **per group** (NOT multiplied)
- **Default**: SIC (per person) if tour_type not specified

**Example 1 - SIC/Group Tour:**
```
Group Temple Tour (SIC): $30/person, 4 adults
Total: $30 × 4 = $120
```

**Example 2 - Private Tour:**
```
Private Ubud Tour: $150/group, 4 adults
Total: $150 (Fixed group price)
```

#### 3. **Transfer Pricing** (Type-Aware)
- **Private Transfers**: Per vehicle (NOT multiplied by adults)
- **SIC Transfers** (Shared): Per person (multiplied by adults)
- **Ferry Routes**: ALWAYS per person (tickets)
- **Detection**: Checks `transfer_type`, `price_per`, and route type

**Example 1 - Private Transfer:**
```
Airport Pickup (Private): $105/vehicle, 4 adults
Total: $105 (NOT multiplied - entire vehicle)
```

**Example 2 - SIC Transfer:**
```
Shared Shuttle (SIC): $15/person, 4 adults
Total: $15 × 4 = $60 (multiplied by adults)
```

**Example 3 - Ferry:**
```
Nusa Penida Ferry: $25/person, 4 adults
Total: $25 × 4 = $100 (always per person)
```

#### 4. **Markup & Currency**
- **Markup**: Default 10% on base total
- **Exchange Rate**: Default 83 INR/USD
- **Final Calculation**:
  ```
  Base Total = Hotel + Sightseeing + Transfers
  Final USD = Base Total × 1.10
  Final INR = Final USD × 83
  ```

## 🗂️ Database Models (Detailed)

### Core Models

#### **Destination**
- `name`: Destination name (e.g., "Bali")
- `code`: Auto-generated code (e.g., "DE001")
- `country`: Foreign key to Country
- `state`: Foreign key to State (optional)

#### **Area**
- `name`: Area/neighborhood name (e.g., "Seminyak", "Ubud")
- `destination`: Foreign key to Destination
- `is_default`: **CRITICAL** - If True, automatically included in searches when user doesn't specify area
- `code`: Auto-generated code (e.g., "AR001")

**Business Rule**: When user says "5 nights in Bali" without specifying area, system selects all areas with `is_default=True`

---

### 🏨 Hotel Models

#### **Hotel**
Main property record:
- `name`: Hotel name (e.g., "Seminyak Suites")
- `destination`: Foreign key to Destination
- `area`: Foreign key to Area (e.g., Seminyak, Ubud)
- `type_of_stay`: hotel/villa/resort/apartment/guesthouse/homestay
- `category`: Foreign key to HotelCategory (e.g., "Villas", "Resorts")
- `is_featured`: Boolean - if True, prioritized in search
- `minimum_nights`: Minimum stay policy (default: 1)

#### **RoomType**
Specific room configurations within a hotel:
- `hotel`: Foreign key to Hotel
- `name`: Room type name (e.g., "Pool Villa", "Deluxe Suite")
- `num_bedrooms`: Number of bedrooms
- `max_occupancy`: Maximum guests allowed
- `room_features`: Description (e.g., "Pool Villa, Garden View")

#### **RoomRatePeriod** ⭐ **PRICING CORE**
Date-based pricing for each room type:
- `room_type`: Foreign key to RoomType
- `season_type`: Foreign key to SeasonType (Normal/High/Peak/Lebaran/Chinese NY)
- `start_date` / `end_date`: Date range for this rate
- **`base_rate`**: **Per room per night for 2 adults** (decimal)
- `currency`: Foreign key to Currency
- `meal_plan_code`: RO/BB/HB/FB/AI
- `extra_bed_rate`: Extra bed cost per night
- `child_with_bed_rate`: CWB (6-12 years) per night
- `child_without_bed_rate`: CWoB (4-5 years) per night

**Example:**
```
Room: Pool Villa at Seminyak Suites
Season: Normal Season (2024-01-01 to 2024-03-31)
Base Rate: $120.00 per room per night (2 adults)
Extra Adult: +25% per additional adult (calculated in code)
Meal Plan: BB (Bed & Breakfast)
```

#### **HotelAmenity** & **HotelAmenityMapping**
- Amenities: Pool, WiFi, Spa, Restaurant, etc.
- Categories: general/room/recreation/dining/business/family

---

### 🎡 Sightseeing Models

#### **SightseeingCategory**
- `name`: Category (e.g., "Nature", "Historical", "Cultural", "Adventure")
- `description`: Category details

#### **SightseeingPoint** ⭐ **MAIN ACTIVITY MODEL**
Individual sightseeing activity:
- `title`: Activity name (e.g., "Tanah Lot Temple Sunset Tour")
- `destination`: Foreign key to Destination
- `area`: Foreign key to Area (e.g., "Ubud" for rice terraces)
- `category`: Foreign key to SightseeingCategory
- `description`: Full activity description
- **`tour_type`**: 'private' or 'sic' (Seat In Coach/Shared)
- `code`: Auto-generated (e.g., "SP001")

#### **SightseeingGroup**
Combo activities (multiple points combined):
- `name`: Group name (e.g., "Ubud Full Day Tour")
- `destination`: Foreign key to Destination
- `area`: Foreign key to Area
- `sightseeing_points`: ManyToMany to SightseeingPoint

#### **SightseeingPrice** ⭐ **PRICING CORE**
Pricing per activity:
- `sightseeing_point`: Foreign key to SightseeingPoint (or null if group)
- `sightseeing_group`: Foreign key to SightseeingGroup (or null if point)
- **`price_adult`**: **Price per adult** (decimal) - multiplied by number of adults
- `price_child`: Price per child (optional)
- `price_infant`: Price per infant (optional)
- `min_group_size`: Minimum group size for this price (default: 1)
- `currency`: Foreign key to Currency

**Example:**
```
Activity: Tanah Lot Temple Sunset
Price Adult: $50.00 per person
Price Child: $25.00 per child (6-12 years)
Min Group: 2 adults

For 3 adults: $50 × 3 = $150.00
```

#### **SightseeingRoster**
Tour schedules:
- `sightseeing_point` / `sightseeing_group`: Which activity
- `start_date` / `end_date`: Availability period
- `days_of_week`: ManyToMany to Weekday (Mon-Sun)
- `start_time` / `end_time`: Tour timings

---

### 🚗 Transfer Models

#### **VehicleType**
Types of vehicles available:
- `name`: Vehicle name (e.g., "Toyota Avanza", "Mercedes S-Class")
- `capacity`: Number of passengers
- `category`: economy/comfort/premium/luxury/suv/van
- `has_ac`: Boolean (air conditioning)
- `is_luxury`: Boolean

#### **ServiceType**
Types of transfer services:
- `name`: Service name
- `service_category`: fixed_route/point_to_point/rental/taxi/airport_shuttle/ferry
- `pricing_model`: fixed/per_km/per_hour/per_day/per_person

#### **TransferRoute** ⭐ **MAIN ROUTE MODEL**
Predefined transfer routes:
- `destination`: Foreign key to Destination
- `name`: Route name (e.g., "Ngurah Rai Airport to Seminyak")
- `from_location`: Foreign key to LocationMaster (starting point)
- `to_location`: Foreign key to LocationMaster (ending point)
- **`route_type`**: one_way/return/day_tour/fullday/halfday
- `estimated_distance_km`: Distance in km
- `estimated_duration_minutes`: Duration in minutes
- `is_multi_stop`: Boolean (for routes with multiple stops)

#### **TransferPrice** ⭐ **PRICING CORE**
Pricing for each route:
- `route`: Foreign key to TransferRoute
- `vehicle_type`: Foreign key to VehicleType
- **`transfer_type`**: 'private' or 'sic' (Seat In Coach/Shared)
- **`price`**: **Price amount** (decimal)
- `currency`: Foreign key to Currency
- **`price_per`**: **CRITICAL** - 'vehicle' or 'person'
  - **vehicle**: Price is for entire vehicle (NOT multiplied by adults)
  - **person**: Price is per passenger (multiplied by adults)
- `is_available`: Boolean
- `is_recommended`: Boolean

**Example 1 - Private Transfer (Per Vehicle):**
```
Route: Airport to Seminyak
Vehicle: Toyota Avanza (6 seater)
Type: Private
Price: $105.00 per vehicle
Price Per: vehicle

For 2 adults: $105.00 (same)
For 4 adults: $105.00 (same - entire vehicle)
```

**Example 2 - Shared Transfer (Per Person):**
```
Route: Airport to Seminyak
Type: SIC (Shared)
Price: $15.00 per person
Price Per: person

For 2 adults: $15 × 2 = $30.00
For 4 adults: $15 × 4 = $60.00
```

#### **RentalPackage** & **RentalPackagePrice**
Hourly/daily car rentals:
- `name`: Package name (e.g., "Half Day Rental - 4 Hours")
- `duration_hours`: Package duration
- `included_km`: Kilometers included
- `price`: Price per vehicle type

#### **FerryRoute**
Inter-island ferry services:
- `from_island` / `to_island`: LocationMaster references
- `operator`: Ferry operator name
- **`price`**: **Always per person** (ferry tickets)
- `direction`: both/one_way

### 📋 Requirement & Quote Models

#### **Requirement**
Customer travel request:
- `destination`: Foreign key to Destination
- `nights`: Number of nights (integer)
- `adults`: Number of adults (integer)
- `children`: Number of children (integer)
- `budget`: Optional budget constraint (decimal)
- `details_json`: Full extracted requirements (JSON)
  ```json
  {
    "destination": "Bali",
    "nights": 5,
    "adults": 2,
    "areas": ["Seminyak", "Ubud"],
    "sightseeing_preferences": ["nature", "cultural"],
    "include": {
      "hotel": true,
      "sightseeing": true,
      "transfer": true
    }
  }
  ```
- `member`: Foreign key to Member (customer)
- `code`: Auto-generated (e.g., "REQ001")

#### **Quote**
Generated quote for a requirement:
- `requirement`: Foreign key to Requirement
- **`price`**: **Final price in INR** (after markup)
- `currency`: Foreign key to Currency
- **`itinerary_json`**: Contains TWO keys:
  1. **`quote_response`**: Retrieved hotels/sightseeing/transfers (full objects)
  2. **`quote_price`**: Calculated pricing breakdown
  ```json
  {
    "quote_response": {
      "primary_quote": {
        "hotels": [...],
        "sightseeing": [...],
        "transfers": [...]
      }
    },
    "quote_price": {
      "primary_quote": {
        "pricing": {
          "hotel_total_usd": 750.0,
          "sightseeing_total_usd": 200.0,
          "transfer_total_usd": 240.0,
          "base_usd": 1190.0,
          "final_inr": 108647.0
        }
      }
    }
  }
  ```
- `description`: Formatted HTML response (sent to customer)
- `code`: Auto-generated (e.g., "QUO001")

def build_transfer_queries(destination, hotel_areas, sightseeing_areas, transfer_scope):
    queries = []

    if transfer_scope.get("airport", True):

    return list(set(queries))  # Remove duplicates

```python
def validate_transfer_result(transfer, hotel_areas, sightseeing_areas, destination):
    """
    Production-grade validation ensuring transfers are within destination.
    """
    
    # Rule 1: Explicit destination must match
    if transfer.metadata.destination:
        if transfer.metadata.destination != destination:
            return False  # ❌ Wrong destination
    
    # Rule 2: Must mention destination OR known area
    valid_location_refs = [destination] + hotel_areas + sightseeing_areas
    
    mentions_location = any(
        loc in transfer.name or 
        loc in transfer.from_location or 
        loc in transfer.to_location
        for loc in valid_location_refs
    )
    
    if not mentions_location:
        return False  # ❌ No location reference
    
    # Rule 3: Airport transfers must mention airport + location
    if "airport" in transfer.route_type:
        return mentions_location  # ✅ if location mentioned
    
    # Rule 4: Inter-area transfers must connect valid zones
    valid_zones = hotel_areas + sightseeing_areas + [destination]
    
    from_matches = [z for z in valid_zones if z in transfer.from_location]
    to_matches = [z for z in valid_zones if z in transfer.to_location]
    
    if from_matches and to_matches:
        return True  # ✅ Connects two valid zones
    
    if from_matches or to_matches:
        return True  # ✅ Connects one zone (with location context)
    
    return False  # ❌ No valid zone connection
```

✅ **VALID:**

**Purpose**: Calculate all price components and apply markup

**Parameters:**
- `quotes_json`: Retrieved quote data
- `nights`: Number of nights
- `adults`: Number of adults
- `exchange_rate`: USD to INR (default: 83)
- `markup_percent`: Commission % (default: 10)

**Returns:**
```python
{
  "primary_quote": {
    "hotels": [...],
    "sightseeing": [...],
    "transfers": [...],
    "pricing": {
      "hotel_total_usd": 750.0,
      "sightseeing_total_usd": 200.0,
      "transfer_total_usd": 240.0,
      "base_usd": 1190.0,
      "base_inr": 98770.0,
      "markup_percent": 10.0,
      "final_usd": 1309.0,
      "final_inr": 108647.0,
      "adults": 3,
      "nights": 5,
      "exchange_rate": 83.0
    }
  }
}
```

### `ensure_areas_for_destination()`
**Purpose**: Get default areas if user doesn't specify

**Logic:**
1. If user specifies areas → use those
2. Else, fetch areas with `is_default=True` from DB
3. Fallback: use destination name as area

**Example:**
- User: "5 nights in Bali"
- System: Auto-selects Seminyak, Ubud, Kuta, Nusa Dua

## 🎯 Business Rules

### Default Sightseeing
- **Always included** unless user says "no sightseeing"
- Count: `max(nights - 1, 2)` activities
- Query: "top sightseeing activities in {area} {destination}"

### Transfer Logic
1. **Airport Transfers**: Always included for first/last hotel
2. **Inter-Area**: When multiple hotel areas (e.g., Seminyak → Ubud)
3. **Sightseeing Day**: Optional transfers to/from activities

### Validation
- **Minimum nights**: 1
- **Minimum adults**: 1
- **Hotel price**: Must be > 0
- **Destination**: Must exist in database

## 📝 Quote Response Format (B2B Terminology)

### Standard Terms
- ✅ "Package Costing" (not "Total Investment")
- ✅ "Pax" (not "Travelers")
- ✅ "Inclusions" (not "Included")
- ✅ "PVT basis" (not "Private transfers")

### Pricing Breakdown Table
```
Component                    | Amount (USD)
---------------------------- | ------------
Accommodation (5 nights)     | $750.00
Sightseeing (4 activities)   | $200.00
Transfers (PVT basis)        | $240.00
---------------------------- | ------------
Total Package Cost           | USD 1,309.00
                             | (Approx. ₹108,647)
```

## 🐛 Recent Fixes

### 1. Adult Pricing Bug (2025-11-27)
- **Issue**: Used addition instead of multiplication
- **Before**: 3 adults = `nights + 1` = 6
- **After**: 3 adults = `base × 1.25`

### 2. Zero Hotel Price Bug (2025-11-27)
- **Issue**: Code checked `hotel` key, but agent returned `hotels` (plural)
- **Fix**: Support both `hotel` and `hotels` keys

### 3. Missing Sightseeing (2025-11-27)
- **Issue**: Only Ubud marked as default, limiting search
- **Fix**: Added Seminyak, Kuta, Nusa Dua as defaults
- **Issue**: Poor vector search query
- **Fix**: Use specific query: "top sightseeing activities in {area}"
